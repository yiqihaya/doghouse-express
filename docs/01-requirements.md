# 01 — 需求规格说明

## 项目背景

用户需要一款 Windows 桌面软件，用于日常收集和管理快递信息。要求界面简洁直观，仿苹果官网设计风格，以淡蓝色为主色调。

## 功能需求

### FR-01 快递信息录入（优先级：P0）

- 录入字段：收件人（必填）、电话号码（必填）、取件码、快递编号
- 可选：上传快递照片（从手机传到电脑后选择文件）
- 录入日期自动取系统当天日期
- 录入精确时间（ISO 8601 时间戳）

### FR-02 快递列表展示（优先级：P0）

- 按录入日期分组显示（同一天的卡片归为一组）
- 日期组按降序排列（最新在上）
- 每张卡片简洁展示：收件人 + 取件码 + 状态角标

### FR-03 详情查看（优先级：P0）

- 点击快递卡片弹出详情弹窗
- 显示全部字段 + 照片（如有）
- 弹窗背景毛玻璃效果

### FR-04 一键复制（优先级：P0）

- 详情弹窗中每个字段旁有复制按钮
- 点击后复制对应内容到剪贴板

### FR-05 搜索筛选（优先级：P1）

- 顶部搜索栏，输入关键词实时过滤
- 模糊匹配：收件人、电话、取件码、快递编号
- 侧边栏按月/日快速筛选

### FR-06 编辑修改（优先级：P1）

- 可修改已录入的快递信息
- 编辑表单预填现有数据
- 支持更换照片

### FR-07 快递状态标记（优先级：P1）

- 已取件 / 未取件 两种状态
- 卡片上可直接切换
- 默认状态：未取件

### FR-08 数据持久化（优先级：P0）

- 使用 SQLite 本地数据库
- 程序关闭后数据保留
- 照片文件存储在本地 assets/ 目录

## 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 启动速度 < 3 秒，百条数据内操作流畅 |
| 可用性 | 无需安装额外软件，双击 exe 即可运行 |
| 兼容性 | Windows 10/11，64 位 |
| 安全性 | 渲染进程不直接访问 Node.js API |
| 可维护性 | 代码中文注释，结构清晰 |
